## Weeks 1–2 Assignment – Preparing for Exploratory Data Analysis, Data Manipulation, and Processing

This assignment introduces the foundational steps required for exploratory data analysis. The work focuses on preparing datasets for analysis using Python and pandas, including data cleaning, restructuring, and transforming data between long and wide formats.

### Key Techniques
- Loading and combining datasets
- Data cleaning and preprocessing
- Type conversion and sorting
- Reshaping data between long and wide formats
- Filtering and pivoting tabular data

### Tools and Libraries
- Python
- pandas
- Jupyter Notebook

Datasets provided as part of the course materials are not included.
