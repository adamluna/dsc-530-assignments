## Weeks 3–4 Assignment – Sampling Methods, Descriptive Statistics, and Data Distribution

This assignment focuses on sampling techniques, descriptive statistics, and understanding data distributions using Python. The work includes generating sample data, calculating summary statistics, exploring covariance and correlation, and analyzing earthquake data to understand statistical patterns.

### Key Techniques
- Sampling methods
- Descriptive statistics
- Covariance analysis
- Correlation analysis
- Percentile and distribution analysis
- Exploratory data analysis

### Tools and Libraries
- Python
- pandas
- NumPy
- statistics
- Jupyter Notebook

Datasets provided as part of the course materials are not included.
