## Weeks 5–6 Assignment – Data Aggregation and Advanced Pandas Operations

This assignment focuses on applying aggregation, binning, reshaping, and time-series techniques using Python and pandas. The work includes filtering and grouping data, creating bins, building crosstabs and pivot tables, computing z-scores, and performing exploratory analysis on earthquake, stock market, and COVID-19 datasets.

Datasets provided as part of the course materials are not included.
