## Weeks 5–6 Assignment – Data Aggregation, Exploration, and Test Statistics

This assignment focuses on applying aggregation and statistical techniques to explore datasets using Python and pandas. The work includes filtering and grouping data, creating bins, building crosstabs and pivot tables, calculating ranked summaries, and performing exploratory analysis on earthquake, stock market, and COVID-19 datasets.

### Key Techniques
- Data aggregation and grouping
- Data binning and categorization
- Crosstabs and pivot tables
- Ranked and percentile-style summaries
- Rolling-average analysis
- Exploratory data analysis
- Basic statistical testing concepts

### Tools and Libraries
- Python
- pandas
- NumPy
- Jupyter Notebook

Datasets provided as part of the course materials are not included.
