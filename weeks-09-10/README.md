## Weeks 9–10 Assignment – Regression, Classification, and Clustering Analysis

This assignment focuses on regression, classification, and clustering techniques using scikit-learn. The work includes k-means clustering, linear regression, and logistic regression applied to wine, star, and planet datasets from the course textbook.

### Key Techniques
- K-means clustering
- Feature scaling and pipelines
- Clustering evaluation using the Fowlkes–Mallows Index
- Linear regression
- Logistic regression
- Train/test split evaluation
- Regression diagnostics and model interpretation

### Tools and Libraries
- Python
- pandas
- NumPy
- matplotlib
- seaborn
- scikit-learn
- Jupyter Notebook

Datasets provided as part of the course materials are not included.
